# Elena Plaxienco — Portfolio

GitHub Pages ready structure.

## Publish
1. Upload `index.html` and the complete `assets/` folder to the repository root.
2. In GitHub: Settings → Pages.
3. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Save.

Do not rename or move files inside `assets/` unless you also update their paths in `index.html`.
